## 🚀 How to Run Locally

### Option 1: Direct in Browser
Simply double-click [`index.html`](file:///Users/marvinandrew/Desktop/Marvins%20Projects/Marvins%20Porttfolio/index.html) to open it in Chrome, Safari, or your default browser.

### Option 2: Using Local Server
```bash
# Using Node.js
npx serve .

# Or using Python
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🌐 How to Deploy to Vercel (Free Live URL)

### Method A: Deploy via Vercel CLI (1-Minute Command)
If you have Vercel CLI installed or via npx:
```bash
npx vercel
```
1. It will prompt you to log into your free Vercel account (GitHub, GitLab, or Email).
2. Accept the defaults (Set up and deploy? **Yes**; Which scope? **Your Account**; Link to existing project? **No**; Project name? **marvin-andrew-portfolio**).
3. Within 15 seconds, Vercel will output your free production URL, e.g.:
   `https://marvin-andrew-portfolio.vercel.app`

### Method B: Deploy via GitHub (Recommended for Automated Updates)
1. Create a repository on GitHub (e.g. `marvin-andrew-portfolio`).
2. Push this folder to your repository:
   ```bash
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/marvin-andrew-portfolio.git
   git push -u origin main
   ```
3. Visit [vercel.com/new](https://vercel.com/new) and click **Import** next to your repository.
4. Click **Deploy**. Vercel will automatically host it for free with automatic SSL and an official `.vercel.app` domain.

Click the **Download CV** button on the page or press `Cmd + P` (or `Ctrl + P`) in your browser. The embedded `@media print` CSS cleanly strips navigation bars and renders a high-resolution, recruiter-ready printed document.
